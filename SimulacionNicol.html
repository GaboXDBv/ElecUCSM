Freno electromagnético por corrientes de Foucault

Simulación educativa de un disco conductor frenado sin contacto por un campo magnético. Permite visualizar el sistema, modificar parámetros, observar la reducción de RPM y revisar los cálculos físicos utilizados.

1. Arquitectura del sistema

El proyecto representa un freno electromagnético sin contacto. Un motor hace girar un disco de aluminio. Al acercar imanes permanentes al disco, el movimiento relativo entre el conductor y el campo magnético induce corrientes de Foucault. Según la ley de Lenz, esas corrientes generan un campo que se opone al movimiento que las produjo.

Entrada Motor

Entrega velocidad al eje.

Elemento móvil Disco de aluminio

Conductor donde aparecen corrientes inducidas.

Frenado Imanes

Generan el campo magnético transversal.

Medición Sensor Hall / Encoder

Obtiene la velocidad de giro.

Control ESP32

Calcula RPM, tiempo y respuesta experimental.

Variable manipulada

Separación entre los imanes y el disco, intensidad del campo magnético y velocidad inicial.

Variable medida

RPM, velocidad angular, par de frenado estimado, potencia disipada y tiempo de desaceleración.

Objetivo experimental

Determinar cómo cambia el tiempo de frenado cuando varía la distancia imán–disco.

3. Sección de cálculos

3.1 Velocidad angular

ω = RPM · 2π / 60

3.2 Momento de inercia del disco

Para un disco macizo:

I = ½ · m · r²

3.3 Campo magnético efectivo

Para esta demostración se usa una aproximación exponencial de la disminución del campo con la separación:

B(g) = B₀ · e−g/g₀

donde g es la separación y g₀ = 12 mm es una constante usada en la simulación.

3.4 Par de frenado aproximado

τf = K · B² · r² · ω

3.5 Ecuación dinámica

I · dω/dt = −τf − b·ω

Se agrega un término pequeño b·ω para representar pérdidas mecánicas del eje, rodamientos y aire.

3.6 Potencia disipada

P = τf · ω

4. ¿Cómo funciona físicamente?

1. El disco gira

El motor entrega energía mecánica y el disco conductor gira con una velocidad angular ω.

2. El conductor cruza el campo

Una región del disco atraviesa el campo magnético producido por los imanes.

3. Se inducen corrientes

El cambio de flujo magnético produce corrientes cerradas dentro del propio disco: las corrientes de Foucault.

4. Aparece una fuerza opuesta

Por la ley de Lenz, el campo creado por esas corrientes se opone a la causa que las produce, generando un par resistente.

5. La velocidad disminuye

La energía cinética rotacional se reduce y parte se transforma principalmente en calor dentro del material conductor.

6. El sensor registra las RPM

Un sensor Hall o encoder puede enviar pulsos al ESP32 para calcular experimentalmente RPM y tiempo de frenado.

Hipótesis experimental sugerida

A menor separación entre los imanes y el disco conductor, mayor será la interacción magnética y menor será el tiempo requerido para reducir la velocidad del disco.

5. Explicación del código HTML

5.1 Estructura HTML

El documento está dividido en cinco secciones principales: arquitectura, simulador, cálculos, explicación física y explicación del código. Los elementos <canvas> se utilizan para dibujar el disco y la gráfica.

5.2 CSS

Todo el diseño se encuentra dentro de <style>. Se usan CSS Grid, tarjetas, variables de color y reglas responsivas para que la interfaz también se adapte a pantallas pequeñas.

5.3 Variables principales de JavaScript

let omega;          // velocidad angular en rad/s
let rpm;            // revoluciones por minuto
let angle;          // ángulo visual del disco
let time;           // tiempo de simulación
let energy;         // energía acumulada disipada
let running;        // estado del simulador

5.4 Conversión de RPM a rad/s

omega = rpm * 2 * Math.PI / 60;

Esta conversión permite trabajar con las ecuaciones mecánicas usando unidades del SI.

5.5 Campo magnético efectivo

const B = B0 * Math.exp(-gapMM / 12);

La expresión no pretende reproducir exactamente la geometría de un imán real. Se usa para representar de forma visual que el campo efectivo sobre el disco cae al aumentar la separación.

5.6 Momento de inercia

const I = 0.5 * mass * radius * radius;

Corresponde a la expresión para un disco macizo que gira alrededor de su eje central.

5.7 Modelo del par de frenado

const torque = K * B * B * radius * radius * omega;

El par aumenta con el campo magnético, el tamaño efectivo del disco y la velocidad. En un desarrollo experimental serio, la constante K debería obtenerse mediante ajuste de datos reales.

5.8 Actualización de la velocidad

const alpha = -(torque + mechanicalLoss) / I;
omega += alpha * dt;
if (omega < 0) omega = 0;

Primero se calcula la aceleración angular negativa y luego se integra numéricamente usando un paso pequeño de tiempo dt.

5.9 Animación

requestAnimationFrame(animate);

El navegador ejecuta repetidamente la función de animación. En cada ciclo se recalculan las magnitudes físicas, se dibuja el disco, se actualizan los indicadores y se agrega un punto a la gráfica.

5.10 Gráfica

El arreglo history guarda pares {t, rpm}. La función drawGraph() convierte esos valores a coordenadas del canvas y dibuja la curva RPM-tiempo.
